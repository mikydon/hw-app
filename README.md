# Domáci tréning 💪

Apka na cvičenie doma bez náradia, asi 13 minút. Funguje v mobile ako aplikácia.

## Ako ju otvoriť
1. Otvor odkaz na stránku v prehliadači Chrome (Android) alebo Safari (iPhone).
2. Pridaj si ju na plochu:
   - **Android (Chrome):** menu ⋮ → *Pridať na plochu* alebo *Inštalovať aplikáciu*
   - **iPhone (Safari):** tlačidlo Zdieľať → *Pridať na plochu*
3. Spúšťaj ju z ikony na ploche ako normálnu apku.

## Čo vie
- 3 tréningové dni (A, B, C) obdeň: tlak, ťah, nohy, brucho
- zahriatie, časovače, zvuky, oddych medzi cvikmi
- obrázok, postup a video ku každému cviku
- výmena cviku, keď ti nejaký nejde
- XP, levely, séria 🔥, ranky (Drevo až Diamant), týždenné výzvy, odznaky
- história s kalendárom a grafom progresu

## Súkromie
Všetky dáta (tréningy, meno, fotka) sa ukladajú len v tvojom telefóne, v tomto prehliadači.
Nikam sa neposielajú. Ak vymažeš dáta prehliadača, história sa vymaže tiež.

## Pre vývojárov
- Zdrojový kód: `src/App.jsx` (React), vstup `src/main.jsx`
- Build: `npm install` a potom `npm run build` → vytvorí `index.html` (všetko v jednom súbore)
- Web beží cez GitHub Pages z vetvy `main`, priečinok `/` (root)
